## 一、EmotiVoice 概览

**EmotiVoice** 是网易有道开源的**中文情感 TTS 引擎**，支持通过自然语言提示词（prompt）控制语音的情感、语速、音调、音量。

| 项目 | 内容 |
|------|------|
| 仓库 | https://github.com/netease-youdao/EmotiVoice |
| 许可证 | Apache-2.0（商业友好） |
| 研发方 | 网易有道 |
| 核心技术 | PromptTTS + SimBERT + HiFiGAN |
| 输出采样率 | 16kHz |

---

## 二、核心架构

```
用户输入文本 + 风格提示词
        │
        ▼
   SimBERT（中文 BERT 变体）
   ── 将中文提示词编码为风格嵌入（style embedding）
        │
        ▼
   PromptTTS 声学模型（JETSGenerator）
   ── 4 个分类头：pitch / speed / energy / emotion
        │
        ▼
   HiFiGAN 声码器
   ── mel-spectrogram → 波形
        │
        ▼
   16kHz WAV 音频输出
```

**关键论文**：PromptTTS（Guo et al., ICASSP 2023, 243 citations）—— 用文本描述作为 prompt 控制语音风格。

**性别控制**：开源版本**不支持**性别参数（原 PromptTTS 论文有，但此实现未包含）。性别通过选择不同的 speaker ID 间接控制。

## 三、风格参数

EmotiVoice 提供 4 个可调风格维度，均通过**中文提示词**控制：

### 3.1 情感（Emotion）— 7 类

| 情感 | 提示词 | 唤醒度 | 星澜适用 |
|------|--------|--------|----------|
| 普通 | `普通` | 中性 | ✅ 首选 |
| 悲伤 | `悲伤` | 低 | ⚠️ 慎用 |
| 开心 | `开心` | 高 | ❌ |
| 生气 | `生气` | 高 | ❌ |
| 惊讶 | `惊讶` | 高 | ❌ |
| 厌恶 | `厌恶` | 高 | ❌ |
| 恐惧 | `恐惧` | 高 | ❌ |

### 3.2 语速（Speed）— 3 档

| 语速 | 提示词 |
|------|--------|
| 普通 | `语速普通` |
| 很快 | `语速很快` |
| **很慢** | `语速很慢` ← 星澜用 |

### 3.3 音调（Pitch）— 3 档

| 音调 | 提示词 |
|------|--------|
| 普通 | `音调普通` |
| 很高 | `音调很高` |
| **很低** | `音调很低` ← 星澜用 |

### 3.4 音量（Volume）— 3 档

| 音量 | 提示词 |
|------|--------|
| 普通 | `音量普通` |
| 很高 | `音量很高` |
| **很低** | `音量很低` ← 星澜用 |

### 3.5 组合提示词示例

EmotiVoice 支持将多个维度拼接为复合提示词：

```
普通 语速很慢 音调很低 音量很低
```

也可尝试更自然的中文描述：

```
轻声细语地慢慢说
用平静温柔的语气轻轻说
低沉安静地朗读
```

## 五、星澜低刺激夜间语音配置（推荐）

针对星澜「月光下的倾听者」定位，推荐以下最低唤醒度组合：

| 参数 | 配置 | 理由 |
|------|------|------|
| Emotion | `普通` | 中性，避免高兴/生气/惊讶/恐惧等高唤醒情感 |
| Speed | `语速很慢` | 舒缓的交付节奏，符合深夜陪伴场景 |
| Pitch | `音调很低` | 低沉、沉稳的声音质感 |
| Volume | `音量很低` | 轻柔、不侵入，像月光下的耳语 |
| Speaker | 8051（Maria Kasper） | Clear, soothing, expressive |

### 完整提示词

```
普通 语速很慢 音调很低 音量很低
```

## 六、避免过度戏剧化/恋爱感/播音腔

### 6.1 问题根因

EmotiVoice 的训练数据来自 LibriTTS / HiFiTTS（英文有声书），**天然带有朗读/戏剧化表现力**。完全"中性化"是核心挑战。

### 6.2 对策

| 策略 | 说明 |
|------|------|
| 情感选 `普通` | 不要选任何带情绪标签的 prompt |
| 语速降到最低 | `语速很慢` 减少"播音节奏感" |
| 音量降到最低 | `音量很低` 弱化剧场投射感 |
| 避用高唤醒 prompt | 不用开心/惊讶/恐惧等 |
| 实验自然中文描述 | 尝试 `轻声细语地慢慢说` 等更日常化的描述 |

### 6.3 已知局限

- 英文 prompt 效果**不可靠**，只推荐中文 prompt
- 没有显式的「恋爱感」「播音腔」标签——这些是 speaker timbre × prompt 组合涌现出来的
- 要实现真正的深夜陪伴中性语音，大概率需要**在中文日常对话数据上微调**

## 七、API 接入

EmotiVoice 提供 **OpenAI 兼容的 TTS API**：

| 项目 | 内容 |
|------|------|
| 端点 | `/v1/audio/speech` |
| 协议 | OpenAI TTS API 兼容 |
| 语速控制 | `speed` 参数（pyrubberband 后处理时域拉伸） |
| 免费额度 | 网易智云提供 13,000 次免费调用 |
| 自部署 | 开源，Apache-2.0，可本地部署 |

### API 请求示例（推测格式）

```json
{
  "model": "emotivoice",
  "input": "星澜想陪你再坐一会儿。",
  "voice": "8051",
  "speed": 0.85,
  "style_prompt": "普通 语速很慢 音调很低 音量很低"
}
```

> ⚠️ 具体 API 参数以 EmotiVoice 仓库 `openaiapi.py` 实际实现为准。

## 九、关键局限（对星澜场景的影响）

| # | 局限 | 影响 | 缓解措施 |
|---|------|------|----------|
| 1 | 模型天然带戏剧化表现力（有声书训练数据） | 可能声线"太有感情"，不像安静陪伴 | 全部参数拉低 + 选 8051 |
| 2 | 英文 prompt 效果不可靠 | 只能用中文调参，调优空间受限 | 专注中文 prompt 工程 |
| 3 | 无显式"中性化"保证 | 无法保证完全不带情感色彩 | 实测 + 多 prompt 组合对比 |
| 4 | 语速控制是后处理（pyrubberband） | 非模型原生，可能引入失真 | 适度拉伸，不过度 |
| 5 | 16kHz 采样率 | 低于 HiFi 标准（44.1k/48k） | 对陪伴场景可接受 |
| 6 | 中文自然度未验证 | 2000+ speaker 均为英文有声书朗读者 | 需要中文实测 |

## 十、对星钥塔罗的建议

### 10.1 短期（P0 验证）

- [ ] 本地部署 EmotiVoice，用星澜实际文案（10-20 条）跑一轮合成测试
- [ ] 对比 8051 / 92 / 102 / 1088 / 1093 五个 speaker 的中文自然度
- [ ] 测试 3-5 组中文风格 prompt（含 `轻声细语地慢慢说` 等自然描述）
- [ ] 录制 A/B 盲测样本，内部评估"陪伴感 vs 播音感"

### 10.2 中期（如语音功能立项）

- [ ] 如果中文自然度不足，考虑微调（fine-tune）—— 在中文日常对话/轻声朗读数据上训练
- [ ] 考虑替代方案：ChatTTS、CosyVoice、FishSpeech 等国产中文 TTS
- [ ] 如选择 EmotiVoice，编写星澜专用 prompt 模板库（按场景：日常问候/深夜/情绪低落/占卜解读）

### 10.3 产品红线（不可破）

- ❌ 不做 ASMR / 耳语 / 气泡音（避免擦边感）
- ❌ 不做过分温柔暧昧的语气（避免恋爱绑定感）
- ❌ 不做"早安叫醒""睡前哄睡"等强绑定功能
- ✅ 只做用户在星澜聊天页主动点击"听星澜说"的语音播放
- ✅ 语音内容必须是已有文案，不实时生成
- ✅ 播放前标注"合成语音·EmotiVoice"
